# Student Grade Calculator

## Project Description

A simple Python application that calculates student total marks, percentage, and grade based on marks entered in five subjects.

## Features

* Enter student name.
* Enter marks in five subjects.
* Calculate total marks.
* Calculate percentage.
* Display student grade.

## Technologies Used

* Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python grade_calculator.py
```
